# ⚠️ IMPORTANT: Hiero 2026 TSC Election – Ballot #1 Re-Run ⚠️ 

During the original voting period, several eligible voters reported that they were unable to access the Helios Voting system due to a technical issue affecting GitHub authentication. In these cases, logging in with GitHub resulted in an HTTP 500 error, preventing affected voters from accessing the ballot and casting their votes while at the same time the vote came to a close. 

During the [**Hiero TSC meeting on September 22, 2026**](https://zoom.us/rec/share/hOGR9vHoL20LGXcCEwrVxiwJBVcJYs_JslwWRcN6uwsVYhtoyWWnQ8p6SzhGRFKR.PYq-JGMSQrknFEH4), the TSC discussed the issue and agreed that the most appropriate way to ensure all eligible voters have an opportunity to participate is to **re-run Ballot #1**.

As a result, the remainder of the election schedule has been adjusted.

## Updated Election Schedule

| Stage | Dates | Description |
| --- | --- | --- |
| Nominations (unchanged) | **Aug 25 – Sep 8** | All nominations were filed as **Maintainer TSC Seat** candidates. |
| Ballot #1 – Maintainer TSC Seats | **Sep 28 – Oct 12** | All eligible maintainers may vote for **2 candidates**. |
| Ballot #2 – TSC Voted Seat | **Oct 13 – Oct 26** | The TSC selects the third candidate from those remaining after the first ballot. |
| Results Announced | **Oct 27** | Final election results are announced. |

## Helios Voting Access

The GitHub authentication issue affecting some users in Helios Voting **has not yet been resolved**.

Eligible voters should first attempt to access Helios using the standard **GitHub login** option.

If you encounter the GitHub login error and are unable to access the ballot, please contact **Jessica Gonzalez (jwagantall@linuxfoundation.org)**.

An alternate Helios login using a **Voter ID and password** can be generated for affected voters so they can access the election and cast their vote.

> **Important:** If you experience problems accessing the ballot, please report the issue before the voting period closes so alternate access can be provided.

## Why Ballot #1 Is Being Re-Run

The goal of re-running the ballot is to ensure that every eligible voter has a reasonable opportunity to participate in the election.

Votes from the previous Ballot #1 will therefore **not be used for the final election result**. Eligible voters will need to cast their vote again during the new voting period from **September 28 through October 12**.

We appreciate the community's patience while we work through the Helios authentication issue and ensure the election process remains accessible to all eligible participants.
